# Licence texts as read

The licence of each model, tool or asset pack that `THIRD_PARTY.md` vets, copied as it read on
the day it was checked. Name each file `<model>_<YYYY-MM-DD>.txt` (for example
`qwen-image-2512_2026-10-14.txt`): lower case, words joined by hyphens, and the date it was read.
A licence that changes later gets a new file beside the old one, and the old file stays. The
`Read` column of THIRD_PARTY.md's models table gives the date of the file its verdict rests on.

The art-gen session sends these through the coordinator, and art-kit commits them; nothing writes
here automatically.

PSYKINETIC

1. Unzip this folder anywhere you like (your Desktop is fine).
2. Double-click launch.bat.
3. The first time, Windows may show a blue "Windows protected your PC"
   box. Click "More info", then "Run anyway". It only asks once.
4. The game asks for the server address and the token. Whoever runs the
   server will give you both. Type them in and click Connect. It remembers
   them, so you will not be asked again.

That is it. Every time you start it with launch.bat it checks for a newer
version first and updates itself if there is one, then starts the game.

Controls: left click to walk or attack, right click to shove, hold right
click and drag to throw something in that direction. F3 shows connection
details.

If something goes wrong, the file update.log in this folder says what the
updater did. To change the address or token, delete settings.cfg and run
launch.bat again.
